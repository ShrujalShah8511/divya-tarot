# 🎴 Divya Tarot | Divine Indian Tarot & Vedic Guidance

> **For India, By Indians** — An interactive, modern web application for authentic Tarot card readings tailored specifically for Indian life contexts, career prosperity, family harmony, and daily karma guidance.

---

## ✨ Features

- 🌟 **Royal Cosmic Aesthetics**: Peacock Blue, Temple Gold, Saffron glow, and an interactive sacred lotus mandala starfield canvas.
- 🎴 **3D Interactive Cards**: Realistic deck shuffling, 3D card flipping animations, and upright/reversed orientation indicators.
- 🇮🇳 **Indian Cultural Spreads**:
  1. **Shubh Muhurat (1 Card)** - Auspicious daily guidance & affirmation.
  2. **Karma & Dharma (3 Cards)** - Past Karma, Present Duty, Future Harvest.
  3. **Dhan & Career Prosperity (3 Cards)** - Jobs, competitive exams, wealth growth.
  4. **Rishta & Family Harmony (4 Cards)** - Love, arranged/love marriage, household peace.
  5. **Navagraha Life Destiny (5 Cards)** - Mind, Career, Dhan, Prema, and Bhagya.
- 🎵 **Procedural Web Audio SFX**: Tanpura-inspired ambient background tone and temple chime card flip audio (with mute controls).
- 📲 **1-Click WhatsApp Sharing**: Easily share reading results and Vedic mantras directly on WhatsApp.
- 📖 **Local Reading Journal**: Save and review past readings stored safely in your browser.
- 🚀 **Free Hosting Ready**: Built to deploy on **Vercel**, **Netlify**, or **GitHub Pages** for free.

## 🚀 How to Host on GitHub & Deploy for FREE

### Step 1: Upload Code to GitHub
Open your terminal in this project directory and run:

```bash
git init
git add .
git commit -m "Initial commit of Divya Tarot"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/divya-tarot.git
git push -u origin main
```

### Step 2: Deploy Free on Vercel (Recommended 1-Click Method)
1. Go to [Vercel.com](https://vercel.com/signup) and sign in with **GitHub**.
2. Click **"Add New" ➔ "Project"**.
3. Import your `divya-tarot` repository.
4. Click **Deploy**.
5. 🎉 Your site will be live instantly with a free URL like `https://divya-tarot.vercel.app` and free automatic HTTPS!

### Alternative Option A: Deploy on Netlify
1. Go to [Netlify.com](https://netlify.com) and log in with GitHub.
2. Click **"Import an existing project"** ➔ Select your repository.
3. Click **Deploy Site**.

### Alternative Option B: Deploy on GitHub Pages
1. In your GitHub repository, go to **Settings ➔ Pages**.
2. Set source branch to `main` and folder to `/ (root)`.
3. Click **Save**.
